## 🚀 Funcionalidades

* **Cadastro e Edição de Produtos:** Adicione novos itens informando nome, categoria, quantidade e preço unitário, ou edite itens já existentes.
* **Controle de Estoque Baixo:** Alerta visual automático na tabela para produtos com menos de 10 unidades em estoque.
* **Busca e Filtros:** Pesquise rapidamente produtos pelo nome ou filtre-os por categoria.
* **Cálculo Automático:** O sistema calcula automaticamente o valor total do item em estoque (Quantidade × Preço Unitário).
* **Reorganização de IDs:** Ao excluir um item, os IDs dos produtos restantes são reordenados sequencialmente.

## ⚙️ Como Executar o Projeto Localmente

Certifique-se de ter o [Node.js](https://nodejs.org/) e a [Angular CLI](https://angular.dev/cli) instalados na sua máquina.

1. **Clone o repositório:**
   ```bash
   git clone [https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git](https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git)

   Entre na pasta do projeto:

```Bash
cd nome-do-projeto
```

2. Instale as dependências:

```Bash
npm install
```

3. Inicie o servidor de desenvolvimento:

```Bash
ng serve
```
4. Abra no navegador:
```
Acesse http://localhost:4200/ para ver a aplicação rodando.
```
